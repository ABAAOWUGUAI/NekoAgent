访问与运行说明

当前控制台
访问凭证来源

登录页的访问凭证来自 Bridge 运行配置指定的 TOKEN_PATH。实际内容只应在服务器上安全读取，不应出现在截图、群聊、普通日志或公开文档中。

会话方式

登录成功后由服务端创建 HttpOnly 会话 Cookie。浏览器页面不会把 token 保存到 localStorage 或 sessionStorage。

API 兼容

管理脚本使用 X-Bridge-Token；AstrBot 使用独立的 X-Channel-Token，且只能访问 QQ 渠道运行面。

公网访问

如果外部电脑或手机打不开页面，优先检查云厂商安全组是否放行 TCP 18777。
