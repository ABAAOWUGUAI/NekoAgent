# 公开源码同步与验收边界（2026-09-30）

本次从**当时已安装**的服务端源码建立逐文件 SHA-256 清单，再把公开范围内的源码、控制台资源和回归测试同步到仓库。公开仓库是可自行部署的源码，不是某个私人实例的数据库、运行配置或生产发布清单；以后两者也可能继续分叉。

## 本次包含什么

- 364 个已安装的顶层 Python 源文件经过公开导出规则处理；私人运维守护进程不在公开边界内。
- 控制台当前装配的页面入口、产品脚本、适配器、样式，以及旧控制台计划启停脚本。新增页面仍复用已有 Bridge API、鉴权和数据库状态源。
- 群聊候选与终检、表情审核锚点、投递和时延分段、Web 请求幂等、记忆纠正、定时计划创建／编辑／归档／恢复的已安装源码。计划更新使用 `expected_revision`；归档不等于删除，恢复不会自动启用。
- 已有的可选 Starter Pack 及其素材授权说明。它不是平台品牌或任何新部署的默认助手。公开版不会自动安装私人实例的形象、Persona、聊天记录或记忆。

本次没有同步运行中的数据库、群／私聊正文、媒体缓存、QQ 登录态、Provider 凭据、服务器地址、生产备份或发布回执。生产 `admin/` 中的实例专属静态形象文件不作为公开控制台默认资源；两份已授权的动态素材仍仅随可选 Starter Pack 分发。公开版的实例外观需要部署者明确选择并安装。

## 如何核验源码

在仓库根目录运行：

```powershell
python tools/run_public_tests.py
python -m pytest -q
python tools/install_starter_pack.py --pack-dir <可选模板目录> --dry-run
```

本次发布前在隔离候选上分别得到公开 Gate 35 项、完整 pytest 57 项通过；逐文件新鲜度检查为 0 项落后，公开内容审计 0 项告警，`git diff --check` 通过。公开审计检查常见凭据格式、非示例私网地址、身份标记、敏感数字和未知二进制；它不能替代部署者对自己新增素材和配置的审查。

## 哪些体验仍待验证

源码测试、生产安装、服务健康与平台 ACK 是不同证据。此次源码同步**不表示**群聊自然回复、表情贴切度、发送时机、目标群参与、主动话题、记忆自然召回、自学习应用或 QQ 客户端显示已通过。私人实例的正式质量门槛仍需最终版本至少 50 条可评新回复、目标群至少 10 条、合格率不低于 90%、严重错误为零；样本不足时保持待验。控制台前三阶段的已登录真实任务路径、冷／热加载、键盘、焦点、对比度与窄屏检查也不能用静态资源哈希代替。

新部署者应按自己的 Assistant、模型、渠道、权限和素材分别验收；不要把本项目的候选测试解释为你的实例已接通 QQ 或完成生产体验验收。
